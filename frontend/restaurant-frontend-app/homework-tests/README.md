# Тести домашнього завдання

Скопіюйте потрібний рівень у `src/app/` і запустіть `npm run test:hw`:

```powershell
# Практичне завдання
Copy-Item -Recurse -Force homework-tests\practice\* src\app\

# Рівень 1
Copy-Item -Recurse -Force homework-tests\level-1\* src\app\

# Рівень 2
Copy-Item -Recurse -Force homework-tests\level-2\* src\app\

# Рівень 3
Copy-Item -Recurse -Force homework-tests\level-3\* src\app\

# Рівень 3 (бонус)
Copy-Item -Recurse -Force homework-tests\level-3-bonus\* src\app\
```
